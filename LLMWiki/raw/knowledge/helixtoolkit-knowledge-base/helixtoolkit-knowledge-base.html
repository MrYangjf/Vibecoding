🏠 知识库概述
HelixToolkit 是一套用于 .NET 的 3D 渲染工具包，基于 SharpDX / DirectX 11 实现。本知识库覆盖其核心架构的所有关键类型。
核心架构层次
ObservableObject ← Geometry3D abstract ← MeshGeometry3D / PointGeometry3D / LineGeometry3D ← MaterialCore abstract ← PBRMaterialCore / PhongMaterialCore / DiffuseMaterialCore DisposeObject ← SceneNode abstract ← GroupNodeBase ← GroupNode ← GeometryNode abstract ← MaterialGeometryNode abstract ← MeshNode / PointNode / LineNode ← LightNode abstract ← AmbientLightNode / DirectionalLightNode / PointLightNode / SpotLightNode
Agent 使用指南
创建任何 3D 场景时，遵循以下固定流程：
1. 创建 EffectsManager + RenderHost
2. 创建 Geometry3D 子类几何体（设置 Positions / Indices）
3. 创建 MaterialCore 子类材质
4. 创建 GeometryNode 子类节点（绑定 Geometry + Material）
5. 创建 LightNode 灯光
6. 用 GroupNode 组织节点树
7. 附加到渲染宿主

🔸 Geometry3D abstract
所有几何体的抽象基类。定义了顶点位置、索引、颜色等核心数据结构，以及 GPU 缓冲区管理和空间查询（八叉树、包围盒）功能。 不能直接实例化，必须使用其子类 MeshGeometry3D、PointGeometry3D 或 LineGeometry3D。
继承关系
ObservableObject ← Geometry3D abstract ← MeshGeometry3D ← PointGeometry3D ← LineGeometry3D
属性表
属性名类型默认值说明
GUID Guid (auto) 唯一标识符，自动生成只读
Positions Vector3Collection? null 顶点位置集合。设置时自动清除 Octree 并更新 Boundnullable
Indices IntCollection? null 索引集合。设置时自动清除 Octreenullable
Colors Color4Collection? null 顶点颜色集合nullable
Bound BoundingBox (empty) AABB 轴对齐包围盒，不参与序列化只读(计算)
BoundingSphere BoundingSphere (empty) 包围球，不参与序列化只读(计算)
Octree IOctreeBasic? null 八叉树加速结构，用于快速射线检测nullable
IsDynamic bool false 是否使用动态缓冲区（适用于逐帧更新的流式数据）
PreDefinedVertexCount int 0 动态缓冲区预定义顶点数量
PreDefinedIndexCount int 0 动态缓冲区预定义索引数量
IsTransient bool false 上传 GPU 后自动清除 CPU 端数据，节省内存
方法表
方法参数返回值说明
UpdateVertices() - void 手动触发顶点缓冲区更新，将 Positions 数据上传到 GPU
UpdateTriangles() - void 手动触发索引缓冲区更新，将 Indices 数据上传到 GPU
UpdateColors() - void 手动触发颜色缓冲区更新
UpdateOctree() bool force void 创建或更新八叉树加速结构。force=true 强制重建
UpdateBounds() - void 手动重新计算 AABB 和包围球
AssignTo() Geometry3D target void 将当前几何体的所有属性复制到目标几何体
SetAsTransient() - void 设置 IsTransient=true，上传 GPU 后自动释放 CPU 端数据
ClearAllGeometryData() - void 清除所有几何数据（Positions, Indices, Colors, Normals 等）
注意事项
  • Geometry3D 是抽象类，不能直接 new，必须使用 MeshGeometry3D / PointGeometry3D / LineGeometry3D
  • 修改 Positions 或 Indices 后会自动清除 Octree，如需使用八叉树需手动调用 UpdateOctree()
  • 使用动态几何体时，务必设置 IsDynamic = true 并预分配 PreDefinedVertexCount，否则每帧会重建缓冲区
  • IsTransient 模式下，上传 GPU 后 CPU 端数据被清除，后续无法再访问 Positions 等属性
🔼 MeshGeometry3D
三角网格几何体，HelixToolkit 中最常用的几何体类型。由顶点位置(Position)和三角形索引(Indices)定义的三角面片集合。 可选附加法线(Normals)、纹理坐标(TextureCoordinates)、切线(Tangents)等数据以支持各种着色模型。
继承关系
Geometry3D abstract ← MeshGeometry3D [Serializable] [DataContract]
创建方式
C# - 直接构造csharp
// 方式1: 空构造 + 手动赋值
var mesh = new MeshGeometry3D();
mesh.Positions = new Vector3Collection {
    new Vector3(0, 0, 0),
    new Vector3(1, 0, 0),
    new Vector3(0, 1, 0)
};
mesh.Indices = new IntCollection { 0, 1, 2 };
mesh.UpdateNormals(); // 自动计算法线

// 方式2: 通过 MeshBuilder 构建
var builder = new MeshBuilder();
builder.AddSphere(Vector3.Zero, 5);
var mesh = builder.ToMesh(); // 返回 MeshGeometry3D，自动计算法线和UV

// 方式3: 通过 Importer 加载
var importer = new Importer();
var scene = importer.Load("model.fbx");
属性表
属性名类型默认值说明
继承自 Geometry3D 的属性: GUID, Positions, Indices, Colors, Bound, BoundingSphere, Octree, IsDynamic, PreDefinedVertexCount, PreDefinedIndexCount, IsTransient
Normals Vector3Collection? null 顶点法线集合不触发 PropertyChanged
TextureCoordinates Vector2Collection? null 纹理坐标(UV)集合会触发 PropertyChanged
Tangents Vector3Collection? null 切线向量集合不触发 PropertyChanged
BiTangents Vector3Collection? null 副切线向量集合不触发 PropertyChanged
TriangleIndices IntCollection? - Indices 的别名，访问的是同一个数据
ReturnMultipleHitsOnHitTest bool false 射线检测时是否返回所有命中结果（而非仅最近点）
静态属性
属性名类型默认值说明
SmallTriangleHitTestScaling float 1e3f 小三角形命中测试缩放因子
SmallTriangleEdgeLengthSquare float 1e-3f 小三角形边长平方阈值
方法表
方法参数返回值说明
继承自 Geometry3D 的方法: UpdateVertices(), UpdateTriangles(), UpdateColors(), UpdateOctree(), UpdateBounds(), AssignTo(), SetAsTransient(), ClearAllGeometryData()
Merge params MeshGeometry3D[] meshes MeshGeometry3D static 合并多个网格为一个（顶点和索引合并）
HitTest context, modelMatrix, ref hits, originalSource bool 射线命中测试，返回是否命中，结果写入 hits 列表
UpdateNormals - void 根据 Positions 和 Indices 重新计算所有顶点法线（面法线平均）
UpdateTextureCoordinates - void 手动触发 UV 缓冲区更新到 GPU
关键陷阱 - GPU 不同步问题
Normals、Tangents、BiTangents 修改后不会自动触发 PropertyChanged，GPU 缓冲区不会自动更新！

正确做法：修改这些属性后，必须手动调用 UpdateVertices() 来通知 GPU 上传新数据。
正确用法示例csharp
mesh.Normals = new Vector3Collection(normalList);
mesh.UpdateVertices(); // 必须手动调用！
最佳实践
  • 使用 MeshBuilder 创建几何体时，ToMesh() 会自动计算 Normals 和 TextureCoordinates
  • 合并多个网格使用 MeshGeometry3D.Merge(mesh1, mesh2, mesh3)
  • 如果只需要颜色不需要光照，可以仅设置 Colors 而不设 Normals
● PointGeometry3D
点云几何体。用于渲染散点数据，如激光扫描点云、粒子效果等。不需要 Indices，每个 Position 独立渲染为一个点。
继承关系
Geometry3D abstract ← PointGeometry3D
创建方式
C# - 创建点云几何体csharp
var pointGeo = new PointGeometry3D();
pointGeo.Positions = new Vector3Collection(pointList);
// 不需要设置 Indices!
属性表
属性名类型默认值说明
继承自 Geometry3D: GUID, Positions, Colors, Bound, BoundingSphere, Octree, IsDynamic, PreDefinedVertexCount, PreDefinedIndexCount, IsTransient
Points IEnumerable<Vector3> - 只读属性，遍历 Positions 的便捷访问器只读
方法表
方法参数返回值说明
HitTest context, modelMatrix, ref hits, originalSource, hitThickness bool 屏幕空间点距离命中测试。hitThickness 控制点击容差半径（像素）
特殊行为
  • 不需要 Indices，仅使用 Positions
  • UpdateBounds() 会保证 Bound 至少 1 单位大小，BoundingSphere 半径至少 1。这是为了防止退化包围盒导致视锥裁剪错误
  • 命中测试在屏幕空间进行，使用像素距离而非世界空间距离
╱ LineGeometry3D
线段几何体。用于渲染线框、边缘、路径等。同时需要 Positions 和 Indices，Indices 按每 2 个一组构成线段（而非三角形中的 3 个一组）。
继承关系
Geometry3D abstract ← LineGeometry3D
创建方式
C# - 创建线段几何体csharp
var lineGeo = new LineGeometry3D();
lineGeo.Positions = new Vector3Collection {
    new Vector3(0, 0, 0),
    new Vector3(1, 1, 0),
    new Vector3(2, 0, 0)
};
// Indices 按每2个一组定义线段: [0,1] = 第一条线段, [1,2] = 第二条线段
lineGeo.Indices = new IntCollection { 0, 1, 1, 2 };
属性表
属性名类型默认值说明
继承自 Geometry3D: GUID, Positions, Indices, Colors, Bound, BoundingSphere, Octree, IsDynamic, PreDefinedVertexCount, PreDefinedIndexCount, IsTransient
Lines IEnumerable - 只读属性，遍历线段的便捷访问器只读
方法表
方法参数返回值说明
HitTest context, modelMatrix, ref hits, originalSource, hitTestThickness bool 屏幕空间命中测试，返回 LineHitTestResult。hitTestThickness 为屏幕像素容差
重要区别
  • Indices 是每 2 个一组构成线段（不是 MeshGeometry3D 的每 3 个一组构成三角形）
  • 命中测试在屏幕空间完成，结果为 LineHitTestResult
  • 与 PointGeometry3D 不同，LineGeometry3D 需要 Indices
🎨 MaterialCore abstract
材质核心基类。定义了 3D 对象的外观渲染方式。三种主要实现：PBRMaterialCore（基于物理的渲染）、 PhongMaterialCore（经典光照模型）、DiffuseMaterialCore（纯漫反射，最简单）。
继承关系
ObservableObject ← MaterialCore abstract ← PBRMaterialCore partial ← PhongMaterialCore partial ← DiffuseMaterialCore [DataContract]
基类属性
属性名类型默认值说明
Name string "Material" 材质名称
GUID Guid (auto) 唯一标识符只读
基类抽象方法
方法说明
CreateMaterialVariables() 创建着色器变量。由子类实现，通常不需要手动调用
材质选择指南
  • PBRMaterialCore: 最逼真的渲染效果，需要环境贴图/IrradianceMap 才能发挥最佳效果。适合产品展示、建筑可视化
  • PhongMaterialCore: 经典光照模型，性能与效果平衡。适合一般 3D 应用
  • DiffuseMaterialCore: 最简单，只有漫反射颜色。适合不需要光照的场景、UI 元素
💎 PBRMaterialCore partial
基于物理的渲染 (Physically Based Rendering) 材质。使用金属度-粗糙度工作流，支持 Albedo/Emissive/RMA(粗糙度-金属度-AO)贴图，可产生高度逼真的渲染效果。
创建方式
C# - 创建 PBR 材质csharp
// 基础 PBR 材质
var pbr = new PBRMaterialCore {
    AlbedoColor = new Color4(0.8, 0.2, 0.1, 1),
    MetallicFactor = 0.9f,
    RoughnessFactor = 0.3f,
    ReflectanceFactor = 0.5f
};

// 带纹理贴图的 PBR 材质
var pbrTex = new PBRMaterialCore {
    AlbedoMap = new TextureModel("albedo.png"),
    NormalMap = new TextureModel("normal.png"),
    RoughnessMetallicMap = new TextureModel("rma.png"),
    RenderEnvironmentMap = true,
    RenderIrradianceMap = true
};
颜色属性
属性名类型默认值说明
AlbedoColor Color4 White 基础颜色（反照率）。PBR 中最主要的颜色属性
EmissiveColor Color4 Black 自发光颜色，不受光照影响
MetallicFactor float 0 金属度因子 (0=非金属, 1=纯金属)。与 RMA 贴图相乘
RoughnessFactor float 0 粗糙度因子 (0=光滑镜面, 1=完全粗糙)。与 RMA 贴图相乘
AmbientOcclusionFactor float 1 环境光遮蔽因子 (0=完全遮蔽, 1=无遮蔽)。与 RMA 贴图相乘
ReflectanceFactor float 0 反射率因子，控制非金属表面的镜面反射强度
ClearCoatStrength float 0 清漆层强度 (0=无清漆, 1=完全清漆覆盖)
ClearCoatRoughness float 0 清漆层粗糙度
VertexColorBlendingFactor float 0 顶点颜色混合因子 (0=不用顶点颜色, 1=完全使用顶点颜色)

💫 PhongMaterialCore partial
经典 Phong 光照模型材质。使用环境光(Ambient) + 漫反射(Diffuse) + 镜面高光(Specular) 三分量光照模型。性能与效果平衡，适合大多数 3D 应用场景。
创建方式
C# - 创建 Phong 材质csharp
var phong = new PhongMaterialCore {
    AmbientColor = new Color4(0.2, 0.2, 0.2, 1),   // 环境光
    DiffuseColor = new Color4(1, 0, 0, 1),       // 漫反射颜色(红)
    SpecularColor = new Color4(1, 1, 1, 1),     // 镜面高光颜色
    SpecularShininess = 32f                      // 高光锐度(越大越集中)
};

// 带漫反射贴图
var phongTex = new PhongMaterialCore {
    DiffuseMap = new TextureModel("texture.jpg"),
    NormalMap = new TextureModel("normal.jpg")
};

🔵 DiffuseMaterialCore [DataContract]
最简单的材质类型，仅有漫反射颜色。不支持法线贴图、位移贴图和细分曲面。适合不需要复杂光照的场景，或与 EnableUnLit 配合使用实现纯色渲染。
创建方式
C# - 创建 Diffuse 材质csharp
// 基础漫反射材质
var diffuse = new DiffuseMaterialCore {
    DiffuseColor = new Color4(1, 0, 0, 1)
};

// 无光照纯色渲染
var unlit = new DiffuseMaterialCore {
    DiffuseColor = new Color4(1, 1, 0, 1),
    EnableUnLit = true // 禁用光照，直接输出颜色
};
属性表
属性名类型默认值说明
DiffuseColorColor4White漫反射颜色
VertexColorBlendingFactorfloat0顶点颜色混合因子
DiffuseMapTextureModel?null漫反射贴图
RenderDiffuseMapbooltrue是否渲染漫反射贴图
EnableUnLitboolfalse禁用光照，直接渲染颜色。适合 UI 元素、纯色标记等
功能限制
DiffuseMaterialCore 不支持：
  • 法线贴图 (NormalMap)
  • 位移贴图 (DisplacementMap)
  • 细分曲面 (Tessellation)
  • 镜面高光 (Specular)
  • 环境反射 (EnvironmentMap)
🗃 SceneNode abstract

🔀 模式 3: GPU 实例化渲染
使用 GPU 实例化一次性渲染大量相同几何体，仅需一次 Draw Call。
🔀 GPU 实例化
C# - GPU 实例化渲染 1000 个立方体csharp
// 创建共享几何体和材质
var builder = new MeshBuilder();
builder.AddBox(Vector3.Zero, 1, 1, 1);
var geo = builder.ToMesh();

var mat = new PhongMaterialCore { DiffuseColor = new Color4(0.2,0.8,0.3,1) };

var meshNode = new MeshNode {
    Geometry = geo,
    Material = mat
};

// 设置实例化矩阵（每个实例一个变换矩阵）
var instances = new List<Matrix>();
for (int i = 0; i < 1000; i++) {
    var x = (i % 32) * 2 - 32;
    var z = (i / 32) * 2 - 32;
    instances.Add(Matrix.Translation(x, 0, z));
}

// 设置 Instances 属性后自动启用 GPU 实例化
meshNode.Instances = instances;
// meshNode.HasInstances 现在为 true
性能优势

🔄 模式 4: 动态几何体（逐帧更新）
适用于顶点数据每帧变化的情况（如粒子系统、流体模拟、变形动画）。
🔄 动态几何体更新
C# - 动态几何体每帧更新csharp
// 创建时声明为动态缓冲区
var geometry = new MeshGeometry3D {
    IsDynamic = true,
    PreDefinedVertexCount = 10000, // 预分配顶点缓冲区大小
    PreDefinedIndexCount = 15000  // 预分配索引缓冲区大小
};

var meshNode = new MeshNode {
    Geometry = geometry,
    Material = material
};

// 每帧更新（在渲染循环中）
void UpdateFrame() {
    // 1. 更新顶点数据
    geometry.Positions = new Vector3Collection(newPositionList);
    geometry.Indices = new IntCollection(newIndexList);

    // 2. 手动通知 GPU 上传（关键！）
    geometry.UpdateVertices();
    geometry.UpdateTriangles();
}
关键要点
  • 务必设置 IsDynamic = true，否则每帧会重建 GPU 缓冲区导致严重性能问题
  • 设置 PreDefinedVertexCount 和 PreDefinedIndexCount 预分配足够大的缓冲区
  • 修改数据后必须手动调用 UpdateVertices() 和 UpdateTriangles()

  • 透明物体之间的排序可能不准确（顺序无关透明 OIT 可以帮助解决）
  • 在 RenderHost 配置中启用 OITRenderType = DepthPeeling 可改善透明渲染质量
