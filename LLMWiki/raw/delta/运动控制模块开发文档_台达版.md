# 运动控制模块开发文档（台达 EtherCAT 版）

> 基于台达 PCI-L221 EtherCAT 主站卡，完全对齐现有雷赛 MotionControl 模块架构
> 目标框架：.NET Framework 4.8 | 模块定位：主程序中的运动控制模块（非独立解决方案）

---

## 1. 架构总览

模块内采用 **三层架构**，自底向上：

| 层级 | 文件夹 | 职责 | 对应雷赛 |
|------|--------|------|----------|
| L1 原生封装层 | `DeltaEtherCAT/Native/` | 对台达 `EtherCAT_DLL.dll` 的 P/Invoke 封装，按功能域分文件 | `LSnmcControler/LTSMC.cs` |
| L2 抽象接口层 | `IMotion/` | 控制器/轴/IO 抽象基类与枚举，**与厂商无关，完全不变** | `IMotion/`（不变） |
| L3 台达实现层 | `DeltaEtherCAT/` | 继承抽象层，调用原生封装层，实现台达特有逻辑 | `LSnmcControler/` |

业务层（`MontionManager` / `Cylinder`）面向 L2 抽象编程，切换厂商时只需替换 L3 实现，业务代码零改动。

## 2. 台达 DLL 分析与 .NET 4.8 兼容性

### 2.1 DLL 性质

安装路径 `D:\Program Files (x86)\Delta Industrial Automation\EtherCAT\dll\` 下：

| 文件名 | 平台 | 性质 |
|--------|------|------|
| `EtherCAT_DLL.dll` | x86 | **原生非托管 C DLL** |
| `EtherCAT_DLL_x64.dll` | x64 | **原生非托管 C DLL** |

判定依据（台达官方示例 `EtherCAT_DLL.cs`）：

```csharp
[DllImport("EtherCAT_DLL.dll", EntryPoint = "_ECAT_Master_Open")]
public static extern ushort CS_ECAT_Master_Open(ref ushort existcard);
```

使用 `[DllImport]` + `EntryPoint`（带下划线前缀的 C 函数名修饰），返回 `ushort` 错误码，是典型原生 C API。

### 2.2 .NET 4.8 能否直接使用？

**不能直接添加引用，必须 P/Invoke 封装。** 与雷赛 `LTSMC.dll` 性质完全相同。

| 对比项 | 雷赛 LTSMC.dll | 台达 EtherCAT_DLL.dll |
|--------|-----------------|------------------------|
| DLL 性质 | 原生非托管 C DLL | 原生非托管 C DLL |
| .NET 4.8 直接引用 | 否 | 否 |
| 调用方式 | `[DllImport("LTSMC.dll")]` | `[DllImport("EtherCAT_DLL.dll")]` |
| 封装类 | `LTSMC.cs`（静态类） | `Native/` 下按功能域分文件 |
| x86/x64 | 单 DLL | 双 DLL，需按平台选择 |

### 2.3 x86/x64 处理

```csharp
#if X86
    private const string DllPath = "EtherCAT_DLL.dll";
#else
    private const string DllPath = "EtherCAT_DLL_x64.dll";
#endif
```

- 项目平台目标必须设为 `x86` 或 `x64`，**不能用 AnyCPU**
- 部署时将对应 DLL 放到可执行文件同目录

### 2.4 台达与雷赛关键差异

| 差异点 | 雷赛 | 台达 |
|--------|------|------|
| 轴定位 | `ConnectNo` + `AxisNo` | `CardNo` + `NodeId` + `SlotNo` |
| 位置单位 | 工程单位（内部转换） | **脉冲单位**（实现层手动转换） |
| 初始化 | 同步完成 | 异步，需轮询 `CheckInitialDone` |
| 伺服使能 | `smc_set_servo_on` | 先 `SetMoveMode(CSP)` 再 `SetSvon(1)`，等状态机 |
| 从站识别 | 不需要 | 需扫描 `VendorID` + `ProductCode` |
| IO 寻址 | `ConnectNo` + `IONo` | `CardNo` + `NodeId` + `SlotNo` + `BitNo` |

## 3. 目录结构

完全对齐现有雷赛 `MotionControl` 模块，将 `LSnmcControler` 替换为 `DeltaEtherCAT`，原生封装层按功能域分子目录：

```
MotionControl/                                    # 运动控制模块（主程序中的一个文件夹）
├── Cylinder.cs                                   # 气缸业务类（不变，厂商无关）
├── MontionManager.cs                             # 运动管理器（不变，仅初始化时 new 类型不同）
│
├── IMotion/                                      # 抽象接口层（完全不变）
│   ├── Type.cs                                   # 枚举定义
│   ├── MontionControl.cs                         # 控制器抽象基类
│   ├── MontionAxis.cs                            # 轴抽象基类
│   ├── MontionIO.cs                              # IO 抽象基类
│   ├── InputIO.cs                                # 数字输入抽象基类
│   ├── OutputIO.cs                               # 数字输出抽象基类
│   ├── IOParam.cs                                # IO 参数类
│   └── InterpolationMontionParam.cs              # 插补运动参数类
│
└── DeltaEtherCAT/                                # 台达实现层（对应原 LSnmcControler）
    ├── Native/                                   # L1 原生封装层（按功能域分文件）
    │   ├── EtherCATMasterNative.cs              # 主站/从站/SDO/PDO 管理
    │   ├── EtherCATMotionNative.cs              # 运动控制（CSP/CSV/CST/回零/软限位）
    │   ├── EtherCATIONative.cs                  # 数字 IO / AD / DA
    │   ├── EtherCATAdvancedNative.cs            # 高级功能（插补/电子凸轮/龙门/运动缓冲）
    │   └── DeltaErrorCode.cs                     # 错误码常量（按功能分组）
    │
    ├── DeltaMontionControl.cs                    # 台达控制器实现（对应 LSnmcMontionControl）
    ├── DeltaMontionAxis.cs                       # 台达轴实现（对应 LSnmcMontionAxis）
    ├── DeltaInputIO.cs                           # 台达数字输入实现（对应 LSnmcInputIO）
    ├── DeltaOutputIO.cs                          # 台达数字输出实现（对应 LSnmcOutputIO）
    └── DeltaSlaveScanner.cs                      # 从站扫描器（台达特有，雷赛不需要）
```

### 3.1 与雷赛目录对应关系

| 雷赛 | 台达 | 说明 |
|------|------|------|
| `LSnmcControler/LTSMC.cs` | `DeltaEtherCAT/Native/*.cs` | 原生 P/Invoke 封装（台达按功能域拆为 4 个文件） |
| `LSnmcControler/LSnmcMontionControl.cs` | `DeltaEtherCAT/DeltaMontionControl.cs` | 控制器实现 |
| `LSnmcControler/LSnmcMontionAxis.cs` | `DeltaEtherCAT/DeltaMontionAxis.cs` | 轴实现 |
| `LSnmcControler/LSnmcInputIO.cs` | `DeltaEtherCAT/DeltaInputIO.cs` | 输入实现 |
| `LSnmcControler/LSnmcOutputIO.cs` | `DeltaEtherCAT/DeltaOutputIO.cs` | 输出实现 |
| （无） | `DeltaEtherCAT/DeltaSlaveScanner.cs` | 从站扫描（台达特有） |
| `IMotion/*` | `IMotion/*` | **完全不变** |
| `Cylinder.cs` | `Cylinder.cs` | **完全不变** |
| `MontionManager.cs` | `MontionManager.cs` | **仅改一行**（new 类型） |

## 4. 文件命名规范

| 规则 | 说明 | 示例 |
|------|------|------|
| 文件名 = 主类名 | 一个文件一个公共类 | `DeltaMontionAxis.cs` |
| 保留雷赛拼写习惯 | `Montion` 不改为 `Motion` | `MontionControl` / `MontionAxis` |
| 实现类前缀 `Delta` | 区分厂商实现，对应雷赛 `LSnmc` 前缀 | `DeltaMontionControl` |
| Native 层按功能域分文件 | 不使用台达原始单一大文件，按 API 域拆分 | `EtherCATMotionNative.cs` |
| Native 方法名保留台达风格 | 对应雷赛保留 `smc_*`，台达保留 `CS_ECAT_*` | `CS_ECAT_Master_Open` |
| 抽象层文件完全不变 | `IMotion/` 下所有文件名与雷赛一致 | `MontionAxis.cs` |

```csharp
public override bool Initialization(ref string strMsg)
{
    // 1. 打开主站，检测卡
    ushort ret = EtherCATMasterNative.CS_ECAT_Master_Open(ref _existCardCount);
    if (ret != DeltaErrorCode.NO_ERROR || _existCardCount == 0) { /* 日志+返回false */ }

    // 2. 遍历初始化每张卡
    for (ushort seq = 0; seq < _existCardCount; seq++)
    {
        ushort cardNo = 0;
        EtherCATMasterNative.CS_ECAT_Master_Get_Card_Seq(seq, ref cardNo);
        ret = EtherCATMasterNative.CS_ECAT_Master_Initial(cardNo);
        _cardNoList[seq] = (ret == DeltaErrorCode.NO_ERROR) ? cardNo : (ushort)99;
    }
    _ConnectNo = _cardNoList[0];  // ConnectNo 映射为 CardNo

    // 3. 轮询等待初始化完成（InitDone==0），超时30s
    DateTime startTime = DateTime.Now;
    ushort initDone = 1;
    while (initDone != 0)
    {
        System.Threading.Thread.Sleep(100);
        EtherCATMasterNative.CS_ECAT_Master_Check_Initial_Done(_ConnectNo, ref initDone);
        if (initDone == 99) { /* 读Initial_Error_Code，返回false */ }
        if ((DateTime.Now - startTime).TotalSeconds > 30) { /* 超时返回false */ }
    }

    // 4. 扫描从站
    _slaveScanner.Scan(_ConnectNo);
    _isInitial = true;
    return true;
}
```

```csharp
public override void ServoOn()
{
    if (!PreMotionCheck("ServoOn")) return;

    // 1. 检查报警（StatusWord bit3 = 0x0008），有报警先复位
    ushort statusWord = 0;
    EtherCATMotionNative.CS_ECAT_Slave_Motion_Get_StatusWord(_ConnectNo, _nodeId, _slotNo, ref statusWord);
    if ((statusWord & 0x0008) != 0)
    {
        EtherCATMotionNative.CS_ECAT_Slave_Motion_Ralm(_ConnectNo, _nodeId, _slotNo);
        System.Threading.Thread.Sleep(50);
    }

    // 2. 设置 CSP 模式 → 3. 伺服使能
    EtherCATMotionNative.CS_ECAT_Slave_Motion_Set_Move_Mode(_ConnectNo, _nodeId, _slotNo, 8); // 8=CSP
    EtherCATMotionNative.CS_ECAT_Slave_Motion_Set_Svon(_ConnectNo, _nodeId, _slotNo, 1);

    // 4. 轮询等待 OperationEnabled（bit2），超时3s
    DateTime start = DateTime.Now;
    while (!IsServoOn())
    {
        System.Threading.Thread.Sleep(20);
        if ((DateTime.Now - start).TotalSeconds > 3) { m_Log.Debug(...); return; }
    }
}
```

```csharp
public override bool AbsMove(double pos, double minVel, double maxVel,

        ToPulse(minVel),             // 起始速度（脉冲/s）
        ToPulse(maxVel),             // 运行速度（脉冲/s）
        ToPulse(stopVel),            // 末速度（脉冲/s）
        accTime, decTime,            // 加减速时间（s）
        (ushort)(sTime * 1000),     // S曲线时间（ms）
        posMode);                     // 0=相对, 1=绝对

    if (ret != DeltaErrorCode.NO_ERROR) { m_Log.Debug(...); return false; }
    return WaitMoveDone();
}
```

## 10. 初始化流程

```

  │
  ▼

  ├─ new DeltaMontionControl(DevName)

  ├─ new DeltaMontionAxis(control, "X轴", nodeId:1, slotNo:0) { MaxVel=50, Equiv=10000, ... }
```

## 13. 注意事项与最佳实践

1. **平台目标必须 x86 或 x64**：不能用 AnyCPU，否则 `DllImport` 因位数不匹配抛 `BadImageFormatException`。

2. **初始化是异步的**：`Master_Initial` 返回后从站仍在初始化，必须轮询 `Check_Initial_Done` 等待 `InitDone==0`，不可立即操作从站。

3. **NodeID + SlotNo 双轴定位**：台达用 `NodeID`（从站地址，拨码设定）+ `SlotNo`（槽号/轴号）定位一个轴。单轴伺服 SlotNo=0，四轴从站 SlotNo=0~3。

4. **脉冲单位转换**：台达原生 API 位置/速度**全是脉冲单位**，`DeltaMontionAxis` 内部通过 `Equiv`（脉冲当量）做工程单位↔脉冲转换。务必正确设置 `Equiv`。

5. **回零参数单位**：`Home_Config` 速度单位是**脉冲/s**，加速时间是**ms**（注意与运动 API 的秒不同），`DeltaMontionAxis.Home()` 已做转换。

6. **伺服使能流程**：需先 `SetMoveMode(CSP=8)` 再 `SetSvon(1)`，然后轮询 StatusWord 等待 OperationEnabled（bit2=1），不能只调 SetSvon 就认为成功。

7. **运动前检查**：所有运动指令要求轴处于 OperationEnabled，否则返回 `NEED_SVON (0x1105)`。`PreMotionCheck()` 统一检查急停、总线状态、报警。

8. **输出电平约定**：对齐雷赛，`SetON()` 写 `0`（NPN 低电平有效），`SetOFF()` 写 `1`。PNP 型需在 `DeltaOutputIO` 中反转。

9. **资源释放**：退出时必须调 `Master_Reset` + `Master_Close`，否则下次初始化可能失败。建议在 `AppDomain.ProcessExit` 或 `Form.FormClosed` 注册。

10. **从站热插拔不支持**：PCI-L221 不支持运行中热插拔，增减从站需重新初始化主站。

11. **日志对象**：`DeltaMontionControl.m_Log` 为静态日志对象，对齐雷赛，需在程序启动时初始化日志组件。
