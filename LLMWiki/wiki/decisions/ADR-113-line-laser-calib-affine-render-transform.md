# ADR-113 线激光校准渲染统一为单一仿射变换

> **决策一句话**：线激光轮廓渲染的校准框、轮廓点与毫米刻度栅格共用同一套仿射变换（像素 = 原点 + 毫米 × 比例，Z 取反）；比例取四角毫米包围盒跨度、原点落点使包围盒居中 ⇒ 校准框恒完整可见且与轮廓严格对齐。

## 背景

换用新英莱线激光相机后，线激光调试页（`LineLaserCamPage`）ImageBox 中的黄色标定框只显示一半、顶边被裁。

旧渲染实现（`EmguALG/LineLaserContour/LineLaserContourAlgorithm.cs`）照搬英莱官方 demo 的角点公式：

```csharp
corners[0] = (center.X - Abs(LeftTopCorner[0] * rate), center.Y - Abs(LeftTopCorner[1] * rate));
```

该式把**绝对**角点毫米坐标当作相对画布中心的偏移量展开，隐含「毫米原点恰落在标定框中心」的前提（等价于 `LeftTopCorner[1] = -LeftBottomCorner[1]`）。前提不成立时，顶边像素 `center.Y - |LeftTopCorner[1]| × rate` 会越过画布上边界。

两处事实把问题锁定在渲染实现而非相机：

1. **角点与轮廓点同属一套坐标系**：主页 `LockContourAxisOnce()` 直接以四角 Min/Max 作为轮廓曲线的轴范围，说明两者都是绝对毫米坐标，渲染必须使用同一变换；
2. **比例本身是对的**：新旧实现的比例在对称标定数据下完全一致，问题只出在角点相对中心的展开方式。

数值仿真（画布 834×554、边距 30、角点 z∈[-60,120]、x∈[-45,45]）复现：旧实现 y 范围 [-52.3, 441.7]，顶边出画布；新实现 y 范围 [30, 524]，完整落在画布内。

> [[lessons/IntelligentLaser-Callback-Mechanism]] §4.1 的「终版」（demo 角点公式 + `center = (w/2, h/2)`）只修正了 demo 的 `fPersent/dwOffset` 中心偏移，未消除「毫米原点居中」这一隐含前提，故在新相机数据上仍然失效——本 ADR 取代该终版。

## 决策

1. **单一仿射变换**：校准模式统一定义 `pixelX = origin.X + mmX × rate`、`pixelY = origin.Y - mmZ × rate`（Z 取反、向上为正），`ToPixel()` 为唯一换算入口。
2. **比例与原点由标定数据决定**：`rate = min((CanvasW-2×Margin)/spanX, (CanvasH-2×Margin)/spanZ)`，`spanX/spanZ` 取四角毫米包围盒跨度；`origin` 取使该包围盒居中于画布的落点 ⇒ 无论毫米原点相对标定框偏置与否，校准框恒完整落在画布内。
3. **三者共用同一变换**：校准框四角、轮廓折线与特征点、毫米刻度栅格全部经 `ToPixel()` 换算；栅格的毫米范围按 `origin` 反算可见区间，标签显示真实毫米值。
4. **视图锚点**：十字线与绿点锚定标定中心点（`calib.Center`）经变换后的位置；该点落在标定区域之外（标定数据异常）时回退包围盒中心。
5. **形状不变**：不折叠为对称矩形、不改变梯形拓扑，只做平移与等比缩放。

## 备选方案

- **沿用 demo 公式、只把 `center` 取标定框包围盒中心**：角点仍按 `center ± |corner × rate|` 展开，毫米原点偏置时顶边依旧越界；否决——错误根源正是「绝对值展开」。
- **按 `halfExtent` + `(corner - Center)` 相对偏移展开**（历史教训页记录的第 3 轮弯路）：脱离角点自身毫米坐标，轮廓与校准框不再共用一套变换；否决。
- **保留旧角点绘制、只把轮廓变换改为相对标定中心**：两套变换并存，校准框与轮廓互相错位；否决——渲染必须单变换。
- **判定为「相机未标定」并给出画面提示**：与事实不符（相机已标定、角点数据有效）；否决——真实根因是渲染端坐标系假设。

## 后果

### 正面

- 校准框恒完整可见，比例尺与标定数据一致。
- 校准框与轮廓曲线严格对齐（角点毫米坐标处像素严格重合），可直接目视核对。
- 对称标定数据下新旧实现像素完全一致 ⇒ 旧相机零回归。

### 负面

- 毫米原点不再固定于画布中心，`origin` 随标定数据浮动，毫米刻度栅格的 0 点随之移动（标签仍是真实毫米值）。
- 轮廓曲线在画布上的绝对位置随标定数据变化（同一轮廓在不同相机摆位下观感不同），属预期。

## 判据

- 角点、轮廓、栅格三者的像素换算必须出自同一 `ToPixel()`；静态判据：不得出现第二处 `center.X + … × rate` 形式的独立换算。
- 对称标定数据下 `origin` 必须等于画布中心、四角像素与旧实现一致（回归判据）。
- 校准框四角必须落在画布内边距范围内（非对称数据的核心判据）。
