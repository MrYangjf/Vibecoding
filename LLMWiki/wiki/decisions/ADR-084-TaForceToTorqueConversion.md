# ADR-084 TA 下压力按 100% 力量基准换算 CST 千分比

> **决策一句话**：TA 下压力（N）按可配置的 100% 力量基准换算成 CST 千分比下发，⛔ 不再把牛顿当千分比直发

## 背景

业主转述台达口径：「PM46 × PM49 = 100% 力量(N)；抛开摩擦力，`PM46*PM49 × 当前电机电流百分比` 就是电机当前推力 N」。
本项目 `TaAuto` 原先执行 `short torque = (short)TaForceN`，把工艺参数里的牛顿值直接当 CST 千分比下发。

**手册核实结论（本地证据）**：
- `wiki/raw/delta/DELTA_IA-GMC_EtherCAT_PM_TC_20250428.pdf` **第 630 页（印刷 11-3）**「11.1 _ECAT_Slave_CST_Start_Move」参数表原文：
  `Target_Torque | I16 | 千分比 | 目標扭力，數值範圍 1 ~ 1000。`
  `Slope | U32 | 0.1%/秒 | 扭力的上升斜率`
- 同册 **第 39 页（印刷 3-10）**「3.3.2 應用範例」原文：`Ratio項目：額定扭力值千分比。舉例來說，若此值為 20時表示 2%額定扭力。`
- 全文（1018 页）与 `DELTA EtherCAT UserGuild.pdf`、`D:\Program Files (x86)\Delta Industrial Automation\EtherCAT` 安装目录内**均未出现 `PM46` / `PM49` 字样** → 手册未覆盖其**数值定义/单位/范围**。
- **2026-11-05 台达人员补充（口头口径，非手册原文）**：`PM46` = 额定电流，`PM49` = 推力常数，`PM46 × PM49` = 100% 推力(N)。手册层面仍未给 PM46/PM49 的数值定义。
- **推导链（取代原「不能确证同量纲 → 按假设实现」）**：推力 = 电流 × 推力常数 ⇒ 电流百分比与推力百分比同刻度；额定区内 `T = Kt·I` ⇒ CST「额定扭矩千分比」与「额定电流千分比」在线性区同比例。故 `目标‰ = 力值N / 基准N × 1000` 成立。
- **成立条件**：线性区（无弱磁、无电流饱和）、不含摩擦。残余边界：扭矩常数的线性度、低速大电流时的饱和、摩擦未计入；极端工况需现场回归。

### 规格数值（2026-11-05 业主口述，未获手册证实）

- 业主给出：送丝轴型号 **31A**、额定电流 **1.4A**、推力常数 **26.1N/A**，`1.4 × 26.1 = 36.54 N`，与先前口述「峰值 37N」只差取整。
- 核实动作：仓库文本（`wiki/raw`、`轴IO气缸配置模板` CSV/XLSX、供应商目录）、两份台达 PDF 全文、`D:\Program Files (x86)\Delta Industrial Automation\EtherCAT`（1816 个文件，含 ESI XML）均**未检索到 31A 型号或其 1.4A / 26.1N/A 规格**；ESI 中的 `031A` 为十六进制默认值，与型号无关 → **规格未证实**。
- 处置：**默认基准保持 37N 不变**（不擅自改为 36.54）；待供应商 31A 规格书到位后，若确认 `PM46=1.4A`、`PM49=26.1N/A`，再把默认值改为 36.54（现场已落盘的值不动）。

## 决策

1. **D1 基准配置化**：新增 `ROOT/TA_HOME/TA_FORCE_100PCT_N`（N），默认 **37**（= 业主口述 1.4A × 26.1N/A = 36.54 的取整；规格未获手册证实，故暂不改为 36.54）；缺键默认 37、不覆盖现场现值；⛔ 运行时读取 PM46/PM49（手册未给数值定义，读取地址/单位未知；现场改机械/换电机只需改配置）。
2. **D2 换算**：`目标‰ = round(TaForceN / TA_FORCE_100PCT_N * 1000)`（`MidpointRounding.AwayFromZero`），保号，限幅 ±1000。
3. **D3 合法性三分支拒绝**：①基准 ≤0/未配置 → 拒绝（⛔ 不按 1:1 兜底）②`|力值| > 基准` → 判「力值越界」拒绝（不静默限幅，否则现场拿到的是缩水利）③换算后为 0 → 拒绝并报 1‰ 分辨率。
4. **D4 日志双单位**：成功 `力值 5.0N / 100%基准 37.0N / 目标力矩 135‰`；每进程首次换算额外打印「基准 = 额定电流 × 推力常数（台达 PM46/PM49 口径）；CST 千分比按额定扭矩线性折算，仅在线性区成立、不含摩擦」。
5. **D5 入口**：系统设置 → TA 电机 → 参数（`AxisConfigForm` TA 特有区「力—力矩换算」），与 ZeroPose 三参同区；保存经 `MontionManager.SaveTaHomeConfig`（只写 ROOT/TA_HOME，不碰现场其它键）。
6. **D6 旧值迁移**：原本把轴配置 `TorqueTarget`(‰) 直抄成 `TaForceN`(N)；改为 `TaForceN = TorqueTarget × 基准 / 1000`，基准无效则跳过迁移并告警。
7. **D7 分辨率**：基准 37N 时 1‰ ≈ **0.037N**；`|力值| < 0.0185N` 会取整为 0 → **拒绝**（理由：取最近档会让 0.01N 静默变成 0.037N，现场不可预期）。若后续确认并改用 36.54N，则 1‰ = 0.03654N、门槛 0.01827N；代码按 `force100 / 1000` **动态计算**，无硬编码阈值，改基准即可，无需改码。

## 备选方案

- **从驱动器读 PM46/PM49 自动算基准**：被否 —— 两参数在本地手册中无定义，读取地址/单位/是否随型号变化均未知；读错会把力放大/缩小数量级。
- **按额定扭矩（N·m）折算**：被否 —— 缺丝杠导程/减速比，且台达给的是推力 N，不是扭矩。
- **维持力值直发 + 只改 UI 提示**：被否 —— 实际出力只有设定值的 3.7%，属功能性错误。
- **超过 100% 时静默限幅到 1000‰**：被否 —— 现场填 100N 只得到 37N，却无任何拒绝提示。
- **小于分辨率时取最近档**：被否 —— 静默改变用户设定值。

## 后果

### 正面
- 填 5N 得到约 4.995N（原 0.185N），力值与工艺意图一致，偏差从 27 倍收敛到 ±0.5%。
- 基准可配置，换电机/改机械无需改代码；日志双单位可直接对账。
- 非法输入（0、超基准、低于分辨率、基准未配置）全部显式拒绝，不再出现「点了没反应/力很小」的隐性失败。

### 负面
- 换算依据是线性区等价推导（扭矩常数线性度、低速大电流饱和、摩擦未计入），极端工况仍有系统偏差，需现场回归标定；**37 与 36.54 的差异尚未定论**（业主口述乘积 36.54 未获 31A 规格书证实，现默认保留 37），现场须拿供应商规格书确认后再决定是否调整基准。
- 基准填错会整体缩放出力，必须靠「基准 ≤0 拒绝 + 日志打印基准」暴露。
- 1‰ 量化误差最大 ±0.0185N（基准 37N）。

## 合并自 ADR-085 · 扭矩爬升速率归位 TA 参数弹窗 + 扭矩方向独立配置

> 2026-11-17 治理轮合并：原页为独立 ADR-084，其现行裁定收归本页；原页文件已删除（**编号不回收**，废止号不复用）。原页的验证过程叙事已按格式契约 R2 剥离至 `logs/log.md`。

**原页决策一句话**：`TORQUE_SLOPE` 的唯一 UI 入口从系统设置「TA 送丝力矩电机」区移到 TA 轴「参数」弹窗并更名「扭矩爬升速率」；同时新增 `ROOT/TA_HOME/TA_TORQUE_DIRECTION`（±1）承载出厂标定的出力方向，工艺页只填力的**大小**。

### 原页决策条目

1. **D1 单一入口**：`TORQUE_SLOPE` 的唯一 UI 入口 = TA 轴「参数」弹窗（`AxisConfigForm` 的「力矩输出」区）。系统设置页 `txtOptTaSlope` / `lblTaSlopeCaption` / 未挂载孤儿 `lblOptTaSlope`、`LoadOpticsFromConfig` 读取块、`ApplyLaserHeadOnForm` 的 1~65535 校验与 `taAxis.TorqueSlope = (uint)slope` 回写**全部删除**；⛔ 不允许出现第二个可写点。
2. **D2 读写落点**：弹窗从 `DeltaAxisConfig.TorqueSlope` 取值显示，Commit 写回 `DeltaAxisConfig`（经 `MontionManager.SaveTaHomeConfig` → `DeltaMotionConfig.SaveConfig()` 落 `AXES/AXIS/TORQUE_SLOPE`）；⛔ **不写 `TA_HOME`**、⛔ 不新增 `TA_HOME/TORQUE_SLOPE` 键。
3. **D3 校验零写入**：`TryReadInt` 风格整数校验 `1~65535`（0 会被驱动器判参数非法、小数会被 `(uint)` 截断成 0），非法即 `AntdUI.Message.warn` 中文提示并 `return false`，弹窗内不写任何字段（含其它合法字段）。
4. **D4 方向配置化**：新增 `ROOT/TA_HOME/TA_TORQUE_DIRECTION`，取值 `+1` / `-1`（存整数，避免 `+` 字符串解析歧义），默认 **+1**；缺键按 +1、不覆盖既有键；属性 setter 归一（任何非负值 → +1），非法值一律回落 +1。理由：TA 轴专有、出厂参数语义，放 `TA_HOME` 而非 `AXES/AXIS` 通用列，避免 CSV 列错位。
5. **D5 工艺页只留大小**：`TaForceN` 语义改为**力的大小（非负）**。`> 0` 且 `≤ TA_FORCE_100PCT_N`；输入负号 → **显式拒绝**并提示「此处只填力的大小，方向在『系统设置 → TA 电机 → 参数 → 扭矩方向』设置」，⛔ 不静默取绝对值（避免工艺人员误以为改了方向）；回填一律 `Math.Abs`，界面不出现 `-5.0`。
6. **D6 下发换算**：`目标‰ = 方向(+1/-1) × round(力大小 / 基准 × 1000)`（`AwayFromZero`），限幅 ±1000；`力大小 × 方向` 的符号与旧 `TaForceN` 负号等价。零值与 1‰ 分辨率拒绝逻辑沿用（`换算后 == 0` 拒绝）。
7. **D7 旧负值迁移（必须留痕）**：`WeldParamManager.MigrateLegacyTorqueTarget` 在完成 `TorqueTarget`(‰) → `TaForceN`(N) 折算后调用 `NormalizeTaForceDirection`：
   - `TaForceN >= 0` ⇒ 不动方向键；
   - `TaForceN < 0` 且 `TA_TORQUE_DIRECTION` **缺键** ⇒ 置 `-1` 并 `SaveTaHomeConfig` 落盘，力值取绝对值，逐条 `Info` 日志「旧力值 -5.0N 方向推断为 -（写入 TA_TORQUE_DIRECTION=-1），力值取绝对值 5.0N」；
   - `TaForceN < 0` 且方向键**已存在** ⇒ **以键值为准、不覆盖**，只取绝对值并 `Warning` 提示「若键为 -1，原反向出力在『大小×-1』下方向一致，但旧负号已消除，请核对现场出力方向」。
   - 内存态 `TorqueDirectionKeyPresent` 仅供迁移判定，**不落盘**。
8. **D8 尺寸与文案**：弹窗行数由 **34 行增至 37 行**（通用区 19 行不变 + TA 特有区 18 行：5 个分区标题 + 13 个字段行；其中新增「力矩输出」分区标题、扭矩爬升速率行、扭矩方向行）。行高 `Font.Height + 14`（下限 30）、标签列宽按字段标签实测、输入列等宽、`Panel.AutoScroll` 兜底、`maxHeight = WorkingArea.Height - 96`，不写死尺寸。Y 轴弹窗（19 行）**零改动**。全仓用户可见中文标签统一为「扭矩爬升速率」，`TORQUE_SLOPE` 英文键名不变。

### 原页背景

1. **扭矩爬升速率归位**：`TORQUE_SLOPE` 属 `DeltaAxisConfig`（XML `AXES/AXIS/TORQUE_SLOPE`），却长期放在系统设置页的「TA 送丝力矩电机」区，与回零/零位等轴参数分散两处；业主希望它跟其余 TA 轴参数同处 TA 轴「参数」弹窗（`AxisConfigForm`），中文标签统一为「扭矩爬升速率」。
2. **方向与大小分离**：工艺设置页只应表达「力有多大」，工艺人员不负责正负号；方向是出厂调试标定值。原 `TaForceN` 用负号兼表反向，导致①工艺页出现 `-5.0` 这类与工艺直觉相反的输入②负号被误改成方向时无任何提示③方向无独立配置项、随力值散落。
3. **读写落点不同**：`TORQUE_SLOPE` 走**轴配置**（`AXES/AXIS`），`TA_FORCE_100PCT_N` 与回零六参走 **`ROOT/TA_HOME`**。两者不能混写，否则 CSV 列错位或覆盖不相关键。

### 原页后果

### 正面
- 扭矩输出三个参数（力大小 / 方向 / 爬升速率）语义清晰、落点明确；TA 参数弹窗成为轴相关参数的单一入口。
- 旧负值自动迁移并留痕，方向不会静默翻转；`TA_Auto` 日志同时给出「力值N / 方向 / 目标‰ / 爬升速率」，现场可直接对账。
- 工艺人员不再面对负号；越界/负值/低于分辨率全部显式拒绝。

### 负面
- 弹窗多 3 行，1080p 工作区下进入竖向滚动（`AutoScroll` 兜底），不再一屏看全。
- 「方向键已存在 + 旧负值」组合存在**双负号翻向**风险，只能靠 Warning 日志提示人工核对。
- `TORQUE_SLOPE` 迁出系统设置页后，老操作员需改到「参数」弹窗维护。
