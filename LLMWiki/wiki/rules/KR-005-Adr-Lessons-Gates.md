# KR-005 ADR 与教训是编码前门禁

> **一句话规则**：ADR 是编码前必查的硬约束，lessons 是编码前必过的门禁

## 适用范围

**适用**：Phase 0 检索与 Phase 2 编码前、以及编码完成后的回看核对。  
**不适用**：与本仓库无关的通用任务。

## 规则正文

1. `wiki/decisions/` 的 ADR 是**编码前必查的硬约束**；编码完成后必须回看逐条核对是否违反。
2. `wiki/lessons/` 的坑是**编码前必过的门禁**；经 index 第五节定位，⛔ 不凭记忆记页名（页会拆分 / 合并）。
3. 同族页用 `tools/adr_new.py check <关键词>` 与 `tools/lesson_new.py check <关键词>` 检索。
4. 只读不判 = 未过：每个相关页都要给出「适用 / 不适用 + 理由」。

## 判据

- ⛔ 违反判定：改码前未读相关 ADR / 教训页；或读了但未给出适用性判定。
- ✅ 机器校验：Phase 0 与 Phase 2 报告各含一份「读过的 ADR / 教训页 + 判定」清单。

## 反例

| 反例（违规写法） | 正解 |
|---|---|
| 「先写完再补看 ADR」 | 编码前先过 ADR 与教训门禁 |
| 读了教训页但不判定是否命中 | 逐页给出适用 / 不适用 + 理由 |
