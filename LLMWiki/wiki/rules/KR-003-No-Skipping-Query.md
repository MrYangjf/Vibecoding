# KR-003 不得跳过 Query

> **一句话规则**：编码前必须完成 Phase 0 知识检索，且先查代码地图再 Grep

## 适用范围

**适用**：任何需要读代码、改代码或给代码结论的任务。  
**不适用**：不涉及本仓库代码的通用知识问答。

## 规则正文

1. 编码前必须执行 Phase 0 检索上下文；⛔ 禁止凭记忆或只读 Skill 文件就动手。
2. Phase 0 从 Step 0.0 读 `wiki/architecture/CodeMap.md`（按源文件索引）开始 —— 命中则把 Step 0.7 的范围从全库收窄到 1~3 个文件。
3. 未命中才回落 Step 0.1~0.5（index → ADR → lessons → modules → api）。
4. 检索结论要落到「哪些文件 / 哪些约束」，⛔ 不能只说「已查过」。

## 判据

- ⛔ 违反判定：未读 CodeMap 即进入编码；或检索报告只写「已检索」而无命中文件与约束。
- ✅ 机器校验：Phase 0 报告含 CodeMap 命中的文件路径列表。

## 反例

| 反例（违规写法） | 正解 |
|---|---|
| 「这个类我知道在哪，直接改」 | 先读 CodeMap 定位，再动手 |
| 「已按流程检索过了」 | 列出命中的页 / 文件与对应约束 |


### 2026-11-17 · 代码记忆优先与 Grep 时机约束
- **变更**：CodeMap 已重构为总览(代码记忆卡+主干依附)+详表分页;Phase 0 先读总览即可建立代码与依附心智模型;命中后直接读对应代码块;禁止一上来全项目 Grep;全库 Grep 仅在 CodeM
- **理由**：业主反馈 CodeMap 利用率低、反复全盘扫描使其失去代码记忆作用
- **影响**：Phase0 报告须含 CodeMap 命中的功能域/文件;Phase2 才允许扫具体代码块
