# 扭矩上限不是「越小越丝滑」——CSP/CST 共用一个值

> **一句话**：位置模式的推动阻抗由驱动器的最大转矩钳位决定，与力矩模式的目标是两个不同的旋钮；要手感一致只能让它们取同一个上限，且该上限必须高于位置保持所需转矩。

## 现象

业主希望「位置模式推动手感和力矩模式一致」，直觉方案是给位置模式单独设一个更小的限值，或让位置模式不设限。实际结果是：两条路都不成立——位置模式单独限值会让两种模式各调各的；不设限则推动阻抗等于额定转矩，手感远重于力矩模式。

## 根因

- 位置模式（CSP）的推动阻抗来自驱动器**最大转矩钳位**（`16#6072` Max torque），不是来自 CST 目标扭矩；力矩模式（CST）的目标另外受 `CST_Start_Move` 的目标值约束。两个旋钮分别管不同的东西。
- `16#6072` 的**运行期可写性**在台达 GMC 手册中未收录，本机亦无 ASDA 对象字典手册 ⇒ 不能设计成「每次进入力矩前动态写上限」，只能在**伺服 OFF 窗口写定值**。
- 台达 PLC 的 `0x6072 + (轴号-1)*0x800` 是**直写 CoE** 的偏移约定；走主站 API（`NodeID + SlotNo`）时寻址由 API 完成，再手工加 0x800 会写到错误的轴。

## 判据

- 一个配置源：`ROOT/TA_HOME/TA_TORQUE_LIMIT_N`；一个换算点：`GetTorqueLimitPerMille()`；一个软件下发点：`SetTorque`。
- 上限必须 ≥ 位置保持实际需要的转矩，否则 Break 保压打滑、定位被外力拖走、并可能报跟随误差。默认取 100% 力量基准（不降额），不允许把非法值兜底成小上限。
- 「目标被钳制」≠「已出力」：驱动器仍需按 `TORQUE_SLOPE` 从当前扭矩爬升；日志必须把这两种状态分开。
- 目标/上限接近 90%（如 270‰/300‰）即为危险比例，必须显式告警而不是静默通过。

## 预防

- 改上限后要重使能伺服才作用于位置模式（驱动侧写在 OFF 窗口）；CST 软件钳制即时生效——交接时必须讲清这个差异。
- 驱动侧写失败/回读不符只告警不阻断使能：软件钳制仍有效，位置模式阻抗退回驱动器自身参数，需现场按 ASDA 对象字典 / ASDA-Soft 核定（⛔ 不再走未经证实的 P 参数旁路）。
- 写 `16#6072` 与写 `16#6098` 是**同一类操作**，必须共用 `DeltaSlaveDevice.ReadSdo/WriteSdo` 同一套握手；⛔ 不在业务类里自拼 `SDO_*` 轮询，也不在 `Set_MoveMode` 之后（切模式占邮箱）紧跟着发 SDO。
- 现场验收用「同一位置手动推轴」分别在 CSP 与 CST 下比对阻尼，不要只看日志里的千分比。
