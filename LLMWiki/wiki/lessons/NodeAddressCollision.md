# 节点号撞号：配置声明的设备不在总线上，握手打到他人节点

> **一句话**：节点号撞号：配置声明的设备不在总线上，握手打到他人节点

## 现象

现场日志：焊接头从站 NODE_ID=0 与 Y 向电机 NODE_ID=0 撞号，握手把 SDO 0x2004 读到 Y 轴伺服上，从站回 abort 0x1302，报 MCU 版本读取失败；随后第三模组连接报从站未装载，两条日志看似两个故障实为一个根因

## 根因

节点号是主站扫描分配的物理地址，同一节点被两个设备声明时后者会向他人发起 SDO/PDO 读写；且占位值 0 与真实节点号 0 无法区分，配置层既无唯一性校验也无 UI 编辑入口，故障静默发生

## 判据

校验同一 (节点号,槽号) 是否被轴与焊接头多方声明；IO 不参与（位寻址可合法共用从站）；冲突方记 Error 报警并跳过装载，不阻断整机初始化；扫描日志必须打印厂商号与产品码，使未识别设备可定位

## 预防

- 配置新增设备时同步确认节点号来源（主站扫描分配，不可编造）与是否已被占用；占位值不得与真实节点号同值；配置项必须同时提供 UI 编辑入口与唯一性校验，三者缺一即会静默故障
